# あいづち・共感練習モード テスト手順

## テスト環境
- URL: http://localhost:3000/conversation/empathy-new
- 前提条件: フロントエンド開発サーバーが起動していること

## テスト項目

### 1. 初期表示の確認
- [ ] ページタイトルが「あいづち・共感練習」と表示される
- [ ] シナリオ1が表示される（「シナリオ 1 / 3」の表示）
- [ ] ①女性の発言「初対面ってやっぱり緊張しますね」が表示される
- [ ] 音声再生ボタンが表示される
- [ ] 「正解を聞く」ボタンは表示されない

### 2. 音声再生機能の確認
- [ ] 再生ボタンをクリックすると音声が再生される
- [ ] 音声URL: https://blobeastasiafor9th.blob.core.windows.net/wild-nyatsby-mp3-test/aizuti1.mp3
- [ ] 音声再生完了後、「正解を聞く」ボタンが表示される

### 3. 正解表示機能の確認
- [ ] 「正解を聞く」ボタンをクリックする
- [ ] ②男性の返し「そうですね！でもお会いできてうれしいです！」が表示される
- [ ] 正解音声が自動再生される
- [ ] 音声URL: https://blobeastasiafor9th.blob.core.windows.net/wild-nyatsby-mp3-test/aizuti1-2.mp3
- [ ] 「次に進む」ボタンが表示される（「戻る」ボタンは表示されない）

### 4. シナリオ2への遷移
- [ ] 「次に進む」ボタンをクリック
- [ ] シナリオ2が表示される（「シナリオ 2 / 3」の表示）
- [ ] ①女性の発言「カフェ巡りが好きなんです。」が表示される
- [ ] 初期状態に戻る（「正解を聞く」ボタンは非表示）

### 5. シナリオ2の動作確認
- [ ] 音声再生（aizuti2.mp3）
- [ ] 正解表示「へぇ〜！カフェって落ち着きますよね☕おすすめのカフェありますか？」
- [ ] 正解音声再生（aizuti2-2.mp3）
- [ ] 「戻る」と「次に進む」ボタンが両方表示される

### 6. ナビゲーション機能の確認
- [ ] 「戻る」ボタンでシナリオ1に戻る
- [ ] 再度「次に進む」でシナリオ2に進む
- [ ] 「次に進む」でシナリオ3に進む

### 7. シナリオ3の動作確認
- [ ] シナリオ3が表示される（「シナリオ 3 / 3」の表示）
- [ ] ①女性の発言「このお店、おしゃれですね」が表示される
- [ ] 音声再生（aizuti3.mp3）
- [ ] 正解表示「ほんとですね！雰囲気もよくて落ち着きます。」
- [ ] 正解音声再生（aizuti3-2.mp3）
- [ ] 「戻る」ボタンと「練習終了」ボタンが表示される

### 8. 練習終了の確認
- [ ] 「練習終了」ボタンをクリック
- [ ] /conversation/modesページに遷移する

## エラーチェック
- [ ] 音声が再生されない場合のエラーハンドリング
- [ ] ネットワークエラー時の動作
- [ ] ブラウザの音声再生ポリシーによる制限への対応

## ブラウザ互換性
- [ ] Chrome
- [ ] Firefox
- [ ] Safari
- [ ] Edge
