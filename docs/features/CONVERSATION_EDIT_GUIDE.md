# 会話データ編集ガイド

## 編集方法

1. VSCodeで `/frontend/public/conversation_segments_editable.json` を開く
2. 以下の項目を編集可能：
   - `speaker`: "A"（女性）または "B"（男性）
   - `name`: "女性" または "男性"
   - `text`: 会話の内容
   - `start`/`end`: 音声の開始・終了時間（秒）

## 編集例

```json
{
  "id": 1,
  "speaker": "A",          // A=女性, B=男性
  "name": "女性",          // 表示名
  "start": 1.0,           // 開始時間（秒）
  "end": 6.38,            // 終了時間（秒）
  "text": "こんにちは！"   // 会話内容
}
```

## 注意事項

- `id` は変更しないでください（順番を保つため）
- `speaker` を変更したら、`name` も合わせて変更してください
  - speaker "A" → name "女性"
  - speaker "B" → name "男性"
- JSONの形式を崩さないよう注意（カンマ、引用符など）
- 編集後は保存してブラウザを更新（F5）すれば反映されます

## セグメントの追加

新しいセグメントを追加する場合：
1. 最後のセグメントの後にカンマを追加
2. 新しいセグメントを追加（idは連番で）
3. start/endの時間を適切に設定

## トラブルシューティング

- 画面に反映されない → ブラウザのキャッシュをクリア（Ctrl+F5）
- エラーが出る → JSONの形式を確認（カンマ、括弧の対応など）
